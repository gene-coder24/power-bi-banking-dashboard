# Power BI Banking Transactions Dashboard

A beginner Power BI dashboard that analyzes banking transactions.

## Features

- Data import and cleaning with Power Query
- DAX measures for total transactions, credit amount, debit amount, and net flow
- KPI cards, category chart, transaction-type slicer, and transaction-detail table
- Date table and one-to-many data model relationship

## Tools

- Power BI Desktop
- Power Query
- DAX

## Files

- `Banking Transactions Dashboard.pbix` — Power BI report
- `banking_transactions.csv` — sample transaction data
